# 💖 相性診断アプリ（15問・分析型）

Streamlitを利用した、価値観の相性を可視化するWebアプリケーションです。  
15個の質問に対して「自分の理想」と「相手の行動」を比較し、一致率から相性を分析します。

## 🌟 主な機能

### 📝 相性診断（15問）
- シチュエーション別の質問（連絡頻度・ケンカ時の対応・愛情表現など）
- 各質問は3択形式
- 自分と相手の回答を並列で入力可能

### 📊 相性分析結果
- 回答一致率をパーセンテージで表示
- 一致率に応じたコメント表示  
  - 80%以上：価値観が非常に近い  
  - 60〜79%：調整可能な相性  
  - 59%以下：ズレが大きい可能性

### 🔍 質問ごとの詳細分析
- 各質問ごとに「一致 / 不一致」を一覧表示

### 🗄 Supabase連携（テスト）
- Supabaseにデータを書き込む接続テスト機能を実装
- 外部データベースとの連携を学習目的で利用
